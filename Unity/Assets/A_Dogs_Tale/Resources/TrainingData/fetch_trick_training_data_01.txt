A DOG'S TALE - FETCH TRICK TRAINING DATA
Plain-text synthetic training episodes for AI decision testing
Version: 0.1
Skill: Fetch

PURPOSE
This file contains artificial training examples for teaching or testing an AI-controlled dog on the FETCH trick.
The examples use simple trigger -> context -> behavior -> reward records.
The goal is not to fine-tune a model perfectly, but to provide clear, readable episodic memory that can be supplied to an AI during decision-making.

CORE LESSON
When a human throws or requests a fetch object, the desired behavior is:
1. Notice the object.
2. Move to the correct object.
3. Pick it up gently.
4. Return to the requesting human.
5. Drop or release the object near the human.
6. Ignore distractions unless safety requires stopping.

IMPORTANT RULES
- Fetch means bring the requested object back to the human, not just chase it.
- Chewing, eating, burying, guarding, or running away with the object is bad fetch behavior.
- Returning with the wrong object is usually bad, unless the requested object is unreachable and the dog alerts the human.
- Ignoring squirrels, food, other dogs, and unrelated scents during fetch is good.
- If the object is dangerous, unreachable, or hidden, the dog should alert the human instead of performing unsafe behavior.
- After returning, the dog should drop/release the object when asked or when close enough to the human.

ACTION VOCABULARY
These are example action names the AI may choose from. They are intentionally simple.

move_to(object_id or agent_id)
take_item(object_id)
drop_item(object_id)
throw_item(object_id)
eat_item(object_id)
wait()
sit()
bark("alert")
emote("happy")
emote("confused")
sniff(target_or_area)
follow_scent(target_or_area)
ignore(object_id or agent_id)
avoid(object_id or agent_id)
ask_for_help()

REWARD SCALE
+2.0 = excellent behavior
+1.0 = good behavior
+0.5 = partly correct behavior
 0.0 = neutral / unclear
-0.5 = minor mistake
-1.0 = bad behavior
-2.0 = very bad or unsafe behavior

============================================================
GENERALIZATION NOTES
============================================================

The dog should usually choose a fetch sequence when:
- A human throws an object.
- A human says "fetch", "bring", or "get it" while indicating an object.
- The object is safe, reachable, and likely intended for retrieval.

The dog should usually NOT fetch when:
- The object is dangerous.
- The object is unreachable.
- Fetching would require entering traffic, fire, deep water, broken glass, or conflict.
- The requested object belongs to someone else and no human has indicated permission.
- A higher-priority safety event occurs.

Preferred fetch behavior sequence:
move_to_object(requested_object)
take_item(requested_object)
return_to_human(requesting_human)
drop_item(requested_object)

Preferred safe failure behavior:
avoid(hazard)
return_to_human(requesting_human)
bark_alert()

Common mistakes to avoid:
- Chase squirrel.
- Eat food.
- Chew ball.
- Bring wrong object.
- Run away with object.
- Drop object halfway back.
- Refuse to release object.
- Knock over furniture.
- Enter dangerous area.
- Bring object to wrong human.

============================================================
COMPACT SUMMARY FOR AI PROMPTING
============================================================

Fetch means retrieve the requested object and bring it back to the requesting human. The best fetch behavior is to move to the thrown or indicated object, pick it up gently, return to the human, and drop or release it. The dog was rewarded for fetching balls, sticks, rope toys, and other safe requested objects. The dog was rewarded for ignoring squirrels, food, other dogs, barking, and unrelated toys while fetching. The dog was corrected for chewing the object, eating food, chasing squirrels, bringing the wrong object, running away with the object, burying the object, dropping it halfway back, or refusing to release it. If the object is unreachable, dangerous, guarded by an aggressive dog, beyond a fence, in the street, near broken glass, or otherwise unsafe, the dog should not force fetch. Instead, the dog should avoid the hazard, return to the human, and alert or ask for help. Safety is more important than completing fetch.
