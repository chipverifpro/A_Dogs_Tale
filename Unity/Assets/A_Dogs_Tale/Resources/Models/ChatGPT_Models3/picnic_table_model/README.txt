Picnic Table 3D Model
======================

Files:
- picnic_table.obj
- picnic_table.mtl

Unity import:
1. Put both files in the same folder under Assets, for example:
   Assets/A_Dogs_Tale/Resources/Models/Furniture/PicnicTable/
2. Drag picnic_table.obj into the scene.
3. Adjust import scale if desired. The model is roughly 3.2m long, 1.6m wide, 1.1m high.
4. Drag the scene object into your prefab folder, for example:
   Assets/A_Dogs_Tale/Resources/Prefabs/Furniture/PF_PicnicTable.prefab

Model notes:
- Separate object pieces are named, so you can inspect or split them in Blender if needed.
- Materials are Wood, WoodDark, and Metal.
- Geometry is intentionally simple: mostly rectangular boards, optimized for game use.
