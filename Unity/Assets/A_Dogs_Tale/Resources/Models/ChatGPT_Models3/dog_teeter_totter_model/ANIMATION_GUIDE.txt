Dog Teeter Totter Model - Unity Animation Guide
===============================================

Files:
- dog_teeter_totter.obj
- dog_teeter_totter.mtl

Recommended Unity import location:
Assets/A_Dogs_Tale/Resources/Models/Agility/DogTeeterTotter/

Suggested prefab location:
Assets/A_Dogs_Tale/Resources/Prefabs/Agility/PF_DogTeeterTotter.prefab


Model scale and layout
----------------------
The model is roughly:
- Length: 4.0 meters
- Board width: 0.42 meters
- Board top height: about 1.0 meter while level
- Pivot is centered at X=0

The OBJ contains named pieces:
- animated_plank_main
- animated_plank_grip_surface
- contact_zone_left / contact_zone_right
- plank_grip_slat_*
- pivot_axle
- hinge plates
- base and support pieces
- stopper pads

For easiest animation, create a clean hierarchy after importing:

PF_DogTeeterTotter
  Base_Static
    pivot_axle
    hinge plates
    base/support/stopper objects
  BoardPivot
    animated_plank_main
    animated_plank_grip_surface
    contact zones
    grip slats
    paw markers

Place BoardPivot at the pivot center:
Position: (0, 0.88, 0)
Rotation: (0, 0, 0)

Then place board child meshes under BoardPivot. If their world positions change when reparenting,
use "Set Parent, preserve world position" in Unity, or manually restore the visual placement.

Animate BoardPivot, not the individual board meshes.


Simple keyframed animation
--------------------------
For a non-physics training obstacle, animate BoardPivot around the local Z axis:

Idle start:
- Z rotation: +10 degrees
- Left end low, right end high

Dog climbs toward center:
- Hold +10 degrees

Dog crosses center:
- Rotate smoothly to 0 degrees

Dog weight passes pivot:
- Rotate to -10 degrees over 0.5 to 1.0 seconds

Dog exits:
- Hold -10 degrees briefly
- Optional: return to +10 degrees slowly, or leave it where it landed

Suggested AnimationClip keys:
Time 0.00: Z = +10
Time 0.60: Z = +10
Time 1.10: Z = 0
Time 1.70: Z = -10
Time 2.20: Z = -10


Physics-ish scripted behavior
-----------------------------
A nicer version is to rotate based on where the dog is standing along the board.

Concept:
- Measure dog position in BoardPivot local space.
- localX < 0 means dog is on the left side.
- localX > 0 means dog is on the right side.
- Convert localX into a target angle.
- Smoothly rotate BoardPivot toward that target.
- Clamp angle so the board does not spin too far.

Example behavior:
- maxTiltDegrees = 12
- targetAngle = -localX / halfBoardLength * maxTiltDegrees
- clamp targetAngle to [-12, +12]
- rotate using Mathf.SmoothDampAngle or Quaternion.RotateTowards

Important:
The sign may need to be flipped depending on which side you consider "entry".


Collider setup
--------------
Use separate colliders rather than relying on the imported mesh collider.

Recommended:
- BoardPivot
  - BoxCollider on the plank, sized roughly:
    Center: (0, 0.09, 0)
    Size: (4.0, 0.18, 0.42)
  - Rigidbody optional, but keep it kinematic if driving the rotation in code.

- Base_Static
  - BoxColliders for supports or a simple bounding collider.
  - Usually static.

For a dog controller using NavMesh or custom MotionModule:
- Treat the board as a moving platform.
- While the dog is on the board, either parent the dog to the board temporarily or apply platform velocity correction.
- If that is too much for now, keep the teeter animation slow and let the dog movement module handle grounding.


Training/gameplay events
------------------------
Useful trigger zones:
- EntryZone_Left
- ContactZone_Left
- PivotZone
- ContactZone_Right
- ExitZone_Right

Possible scoring:
- +1 dog steps on entry contact zone
- +1 dog reaches pivot
- +1 dog waits calmly while board tips
- +1 dog touches far contact zone
- +1 dog exits without jumping off

For A Dog's Tale, this could become an InteractionModule object with commands:
- examine_teeter
- cross_teeter
- train_teeter
- wait_on_teeter
- reward_contact_zone


Suggested module structure
--------------------------
PF_DogTeeterTotter
  WorldObject
  InteractionModule
  TeeterTotterModule

TeeterTotterModule responsibilities:
- Track current tilt angle
- Track dog/agent currently on board
- Convert agent local position into target angle
- Rotate BoardPivot smoothly
- Emit events when contact zones/pivot/exit are reached
- Log events to BottomBanner
