Tennis Ball Launcher Machine + Separate Tennis Ball - Unity Notes

Files:
- tennis_ball_launcher_machine.obj
- tennis_ball.obj
- tennis_ball_launcher_set.mtl

Design:
- Tennis ball launcher machine with:
  - Blue machine body
  - Orange open hopper/bin full of visible tennis balls
  - Angled front launch barrel
  - Launch muzzle ring
  - Control panel with screen/buttons
  - Large transport wheels
  - Rear handle
  - Guide markers for loading, turning on, launch point, and motor noise
- Separate tennis_ball.obj:
  - Single tennis ball with bright felt material
  - Raised curved seam bands

Unity setup:
1. Import both OBJ files and the shared MTL together.
2. Create prefabs under something like:
   Assets/A_Dogs_Tale/Resources/Prefabs/Props/DogToys/
3. Delete or hide Guide_* groups before final visual use, or keep them on an editor/helper layer.
4. Suggested colliders:
   - Launcher: BoxCollider around body, optional trigger over hopper, small collider at control panel.
   - Tennis ball: SphereCollider with radius matching the mesh.
5. Use Guide_Launch_Muzzle_Point as the spawn/launch origin for tennis_ball prefab instances.
6. Optional_launch_direction_guide_delete_or_hide shows the approximate launch direction and should be hidden in normal gameplay.

Gameplay ideas for A Dog's Tale:
- Machine periodically launches tennis balls for fetch gameplay.
- Dogs can react to motor noise, chase launched balls, retrieve balls, or load balls into hopper.
- Roomba can bump into the machine and accidentally trigger it.
- Squirrels can steal balls from the hopper.
- Use control panel as an interaction target for player or dog paw/nose press.
- Strong behavior hooks:
  - TurnOnLauncher
  - LoadBall
  - FetchBall
  - ChaseLaunchedBall
  - ReactToSound

OBJ limitation:
- OBJ stores mesh/materials only.
- It does not store Unity colliders, Rigidbody, scripts, projectile launch logic, sounds, particles, animations, or prefab hierarchy.
